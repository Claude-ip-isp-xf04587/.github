<p>问「住宅 IP 池怎么选」的人，通常已经踩过一次坑：买回来一查归属，发现半个池子里标着数据中心；或者头几天用着顺，放量到二十个号开始集体要验证。这些问题其实都能在采购前问清楚，只是没人把该问的顺序排出来。这篇按真实的提问顺序串五个问题，从池子里的东西是什么，到小批量试完怎么接上量，每个问题给查询字段、判定门槛和落地动作，报价区间的数字仅供参考。</p>

<h2>一、第一个问题：池子里的「池」到底池的是什么</h2>
<h3>三种池，差别在调度方式</h3>
<p>第一种是固定池，每条 IP 长期分配给一个账号，随用随取，不轮换。第二种是轮换池，按请求或按时间自动换出口，适合抓取类任务。第三种是半固定池，允许手动指定某条 IP 占用一段时间，到期释放。多账号运营要的是第一或第三种，第二种基本不能用，因为登录态需要地址不跳。</p>
<h3>池子大小不等于可用数量</h3>
<p>宣传里的「十万 IP 池」指的是资源总量，跟你实际能同时占用的数量是两回事。要问清同时在线并发上限、单账号可独占的条数、以及同一城市能给出多少条。一个真实可用的池子，能在目标城市稳定给出你需要的条数，并且每条都能查到完整的归属信息。</p>

<h2>二、第二个问题：双 ISP 归属信息该看哪几栏</h2>
<h3>四栏要一起看</h3>
<p>ASN 编号与所属机构、IP 类型（住宅/机房/移动）、所属城市与邮编、上游运营商数量。四栏齐全且互相自洽，才算一条合格的记录。自洽的意思是城市与 ASN 覆盖范围吻合，不能出现 ASN 属某个小区域运营商、城市却是另一个大区的情况，那通常是广播地址。</p>
<h3>双 ISP 的意义在冗余</h3>
<p>一条线路同时挂着两家上游，任一条抖动时可以切另一条，出口地址保持不变。判断是否真的双上游，可以看 traceroute 的第二跳是否出现两个不同的运营商网关，或者看服务商提供的线路说明里是否列出两条上游。只在宣传语里写「双 ISP」而查不到上游信息的，按单 ISP 对待。</p>

<h2>三、第三个问题：干净的路由记录指哪些字段</h2>

<h3>三个可以直接查的痕迹</h3>
<p>一是历史滥用记录，多数公开 IP 库会给出风险分或代理标记，分数越低越理想，超过中位的先跳过。二是反向解析，住宅 IP 一般没有 PTR 记录，若解析出一串像机房域名的名字，说明这条地址曾经被托管过。三是 BGP 历史，短时间内频繁更换宣告方的地址，说明归属不稳定，长期挂着容易漂移。</p>
<h3>干净是相对的</h3>
<p>没有绝对干净的地址，只有相对没被滥用的地址。实操上按「风险分低、无 PTR、宣告方半年内未变」三条筛，能过滤掉大部分问题线。筛完不要立刻全量上，先按下面第四问的方式小批跑。</p>

<h2>四、第四个问题：先试水，试到什么程度算数</h2>
<h3>三条线、七天、四个指标</h3>
<p>试水不是开通一条登录一次就算完。最少三条线，覆盖你未来要用的主要城市，连续观察七天。四个指标：首次连通耗时、七天内的断连次数、出口地址变化次数、登录时被要求验证的比例。前三个是线路质量，最后一个是综合结果。</p>
<h3>门槛怎么定</h3>
<p>经验门槛是这样：首次连通在十秒内、七天断连不超过三次、出口地址零变化、验证比例低于两成。四条都过，可以谈放量；有两条不过，直接换供应商，别指望调参数能救回来。试水期把每天的记录写进同一张表，别靠回忆。</p>

<h2>五、第五个问题：跑通之后怎么接上量</h2>
<p>放量阶段最容易出错的是节奏，而不是数量。建议按周分档，每档不超过上一档的一倍，同时把新线单独放在一组观察，不要和老线混在一个出口分组里。下表是常见的三档放量节奏，可按自己的账号量调整，数字仅供参考。</p>

<h2>常见问答</h2>
<h3>池子里的 IP 会不会被别人用过？</h3>
<p>答：共享型池子无法保证完全未被使用，只能通过风险分、PTR、BGP 历史三项筛出相对干净的。要彻底避免，就选独占型，一条线只分配给你，价格高一些但溯源清楚。是否值得为独占付费，取决于账号的价值和你能承受的验证频率。</p>
<h3>双 ISP 出口切换时，登录态会掉吗？</h3>
<p>答：正常切换对外地址不变，登录态一般不受影响；但如果切换过程中有几十秒的中断，正在提交的表单可能失败。建议把重要操作放在网络稳定的时段，并在客户端开启自动重试，重试间隔设在十秒以上，避免短时间连续请求。</p>
<h3>按量计费和按条包月怎么选？</h3>
<p>答：看在线时长。每天在线超过四小时的，包月更划算；零星使用、每月只跑几次的，按量更省。两种计费方式的单价差通常在两到三倍，具体以服务商报价为准，这里给的比例仅供参考。</p>
<h3>试水期发现一条线不合格，能直接退吗？</h3>
<p>答：开通前先问清更换与退款口径，包括多少天内可换、换线是否计费、未使用流量是否折算。把答复写进订单备注，比事后口头协商有用。多数自营线路支持试水期内免费换一次，具体条款以合同或订单页为准。</p>
